# Feature Roadmap

## Noteworthy Dates

- Oct. 31: Supabase issue ([see here](https://github.com/orgs/supabase/discussions/45329)) goes into effect. Need to fix before then.
- Nov. 3: First AP poll comes out (between wks 9-10)
  - Could be a chance to build out the leaderboard

## Upcoming Features

#### High Priority

- User can see all other users' picks.
- User can view a live leaderboard tallying each submission's points.
  - Need a way to keep updated ranking info when it comes out--either manual, weekly entry or an API
- Stats page: View Ty's notes

#### Medium Priority

- User can see "sleeper" teams when viewing their own and other users' submissions
  - A sleeper team is a pick that few others chose, giving that submission an outsized advantage if the team makes the playoff.

#### Low Priority

- User can submit *new* picks before the start of the season.
- Results are provided to all users at the end of the season.
- Winner of the season is shown to all users at the end of the season.
